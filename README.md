# Portafolio-Tkd

🥋 Portafolio de Taekwondo

Sitio web de presentación para un instructor de Taekwondo 2.º Dan, desarrollado para mostrar su trayectoria deportiva, experiencia competitiva y metodología de enseñanza.

La página presenta la información mediante un diseño oscuro inspirado en las artes marciales, utilizando los colores característicos del Taekwondo y una estructura adaptable a computadoras y dispositivos móviles.

📋 Secciones

Inicio: presentación principal, graduación y resumen de experiencia.

Sobre mí: trayectoria, certificación, especialidades y experiencia docente.

Competencias: exposición de participaciones y resultados deportivos.

Enseñanza: explicación de la metodología y los tipos de entrenamiento ofrecidos.

Contacto: información para consultar por clases individuales, grupales o preparación competitiva.

✨ Características

Navegación interna entre las distintas secciones.

Diseño responsive para celulares, tablets y computadoras.

Animaciones de entrada y efectos al pasar el cursor.

Presentación visual de estadísticas y logros.

Formulario de consulta con acceso mediante correo electrónico.

Uso de tipografías externas de Google Fonts.

🛠️ Tecnologías utilizadas

HTML5

CSS3

Google Fonts

⚠️ Estado del proyecto

El sitio funciona como una presentación web estática. Antes de publicarlo, deben reemplazarse los datos de ejemplo —teléfono, correo, resultados y estadísticas— por información real del instructor.

El formulario de contacto no utiliza una base de datos ni un servidor: actualmente abre el cliente de correo del visitante mediante un enlace mailto:.

🎯 Objetivo

Este proyecto fue creado para practicar maquetación web, diseño responsive y organización de contenido mediante HTML y CSS, aplicándolos a una página profesional vinculada con el Taekwondo.
